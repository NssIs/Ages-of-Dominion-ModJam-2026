# Ages of Dominion

Ages of Dominion is a Minecraft 26.1.2+ NeoForge mod created by Hyrrx for the CurseForge ModJam
2026.

## Why the name

The name reflects the journey from a first banner to a dominion shaped by the player.

## Development

- Java 25 is required.
- Build with `./gradlew build`.
- Run a client with `./gradlew runClient`.
- Generate data with `./gradlew runData`.
